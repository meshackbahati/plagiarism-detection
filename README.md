# Plagiarism and AI Content Detection Tool

A locally deployable tool for detecting plagiarism and AI-generated content in documents and text.

## Features

- **Plagiarism Detection**: Compare documents against each other to find similarities.
- **AI Content Detection**: Detect if text was likely generated by AI (GPT, etc.).
- **Batch Processing**: Upload multiple files at once for analysis.
- **Local First**: Designed to run on your own machine.
- **Support for Multiple Formats**: PDF, DOCX, and TXT files.

## Quick Start (Local Tool)

The easiest way to run the tool is using Docker.

### Prerequisites

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running.

### Installation & Run

1.  **Clone the repository**:
    ```bash
    git clone <repository-url>
    cd plagiarism-detection
    ```

2.  **Start the application**:
    ```bash
    docker compose up -d
    ```

3.  **Access the tool**:
    - Frontend: [http://localhost](http://localhost)
    - API Documentation: [http://localhost:8000/docs](http://localhost:8000/docs)

### How to Use

1.  Open the dashboard at [http://localhost](http://localhost).
2.  Go to the **Upload** section.
3.  Upload your documents or paste the text you want to analyze.
4.  Choose the analysis options (Plagiarism, AI Check, or both).
5.  View the results on the dashboard or the specific batch results page.

## Project Structure

- `frontend/`: React + Vite application.
- `backend/`: FastAPI application.
- `infra/`: Infrastructure configuration (if any).
